# منصة المهرة قريب — نسخة الترحيل المستقلة

هذه نسخة منفصلة عن مشروع Manus الأصلي، أُعدت لرفع الكود إلى مستودع GitHub خاص ثم تجهيز نشر خارجي. لم يتم تضمين أسرار أو قاعدة البيانات أو ملفات السجلات المؤقتة.

## ما تحتويه النسخة

- واجهة React وملفات التصميم الخاصة بمنصة المهرة قريب.
- خادم Express وواجهات tRPC الحالية.
- مخطط Drizzle وجميع migrations الموجودة.
- اختبارات المشروع.
- ملفات `robots.txt` و`sitemap.xml` وبيانات SEO.
- إعداد `vercel.json` ومحول `api/index.ts` لواجهات API.
- أيقونات PWA المحلية والأصل العام الذي أمكن تنزيله بأمان.

## ملاحظة مهمة قبل النشر

النسخة ليست نقلًا مكتملًا للبيانات بعد. قاعدة البيانات والصور الحالية محفوظة خارج ملفات المشروع، وبعض الصور تشير إلى `/manus-storage/` التابع لـ Manus. يجب نقلها إلى قاعدة MySQL/TiDB وتخزين صور خارجي قبل جعل Vercel هو الموقع الأساسي.

كما أن وظائف الخلفية الحالية تعتمد في التخزين وبعض التكاملات على Manus Forge. يجب استبدالها ببيانات اعتماد التخزين الخارجي قبل اعتماد النسخة للإنتاج. لذلك لا تحذفي مشروع Manus ولا توقفيه حتى يكتمل اختبار الترحيل.

## تشغيل محلي

```bash
pnpm install
cp docs/env.example .env
# املئي المتغيرات في .env محليًا فقط
pnpm check
pnpm build
pnpm start
```

## GitHub

1. أنشئي مستودعًا Private.
2. ارفعي هذه النسخة فقط.
3. لا ترفعي `.env` أو كلمات المرور أو مفاتيح S3 أو نسخ سندات الدفع.
4. احفظي نسخة قاعدة البيانات والصور في مكان خاص منفصل.

## Vercel

1. اختاري Import Project من GitHub.
2. اتركي Framework على Vite أو استخدمي إعداد `vercel.json` الموجود.
3. أضيفي متغيرات البيئة من `docs/env.example` داخل Vercel، وليس داخل GitHub.
4. نفذي النشر التجريبي أولًا.
5. اختبري `/api/trpc`، تسجيل الإدارة، إضافة مشروع، رفع صورة، والروابط الخاصة.

## نقل قاعدة البيانات دون فقدان

1. خذي نسخة SQL كاملة من قاعدة Manus قبل أي تغيير.
2. أنشئي قاعدة MySQL/TiDB خارجية.
3. طبقي migrations بالترتيب من `drizzle/`.
4. انقلي الجداول والبيانات مع الحفاظ على المعرفات والعلاقات.
5. قارني عدد المشاريع والمنتجات والطلبات والصور قبل وبعد النقل.
6. لا تفتحي الموقع الخارجي للزوار قبل نجاح المقارنة.

## نقل الصور والملفات

1. استخرجي جميع مفاتيح الصور من حقول المشاريع والمنتجات والطلبات.
2. نزلي الأصول من التخزين الخاص بصلاحية مؤقتة.
3. ارفعيها إلى S3 أو Cloudflare R2 أو تخزين خارجي مماثل.
4. حدّثي روابط الصور في البيانات إلى التخزين الجديد.
5. اختبري صور الغلاف والمعارض والشعارات وسندات الدفع.
6. اجعلي سندات الدفع خاصة ولا تضعي روابطها في HTML العام.

## الحالة الحالية

- مشروع Manus الأصلي محفوظ ولم يُعدّل من هذه النسخة.
- هذه النسخة مستقلة في مجلد منفصل.
- لا توجد بيانات اعتماد أو قاعدة بيانات داخل المستودع.
- لا يُنصح بإعلان أن Vercel جاهز للإنتاج قبل إكمال نقل قاعدة البيانات والتخزين.
